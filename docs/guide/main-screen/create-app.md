# Create Button

The **Create** button at the bottom of [My Apps](/guide/main-screen/my-apps) is the entry point for making a new app.

## How it works

- Tap **Create** (the ＋ icon rotates and the label switches to **Close**).
- A panel expands above the button with a **3-column grid** of the app types.
- Tap a type to open its creation flow. Tap the button again (or a type) to collapse.

## The type grid

| | | |
| --- | --- | --- |
| [Web](/guide/app-types/web) | [Multi-Web](/guide/app-types/multi-web) | [HTML](/guide/app-types/html) |
| [Offline Pack](/guide/app-types/offline-pack) | [Frontend](/guide/app-types/frontend) | [Gallery](/guide/app-types/gallery) |

See [Create App](/guide/app-types/) for how to choose a type and what each one does.

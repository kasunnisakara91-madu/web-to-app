# 创建按钮

[我的应用](/zh/guide/main-screen/my-apps)底部的 **创建** 按钮是新建应用的入口。

## 工作方式

- 点击 **创建**(＋ 图标旋转,标签切换为 **关闭**)。
- 按钮上方展开一个面板,含应用类型的 **3 列网格**。
- 点击某类型打开其创建流程。再次点击按钮(或某类型)收起。

## 类型网格

| | | |
| --- | --- | --- |
| [网页](/zh/guide/app-types/web) | [多站点](/zh/guide/app-types/multi-web) | [HTML](/zh/guide/app-types/html) |
| [离线包](/zh/guide/app-types/offline-pack) | [前端](/zh/guide/app-types/frontend) | [画廊](/zh/guide/app-types/gallery) |

如何选择类型以及每种类型能做什么,见[创建应用](/zh/guide/app-types/)。

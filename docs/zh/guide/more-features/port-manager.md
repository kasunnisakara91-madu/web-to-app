# 端口管理

端口管理是内置的本地站点端口协调器 —— 它没有自己的界面,在后台静默工作。多站点应用可以把打包的应用(HTML、前端、画廊)作为站点嵌入,这些站点通过应用内的回环端口对外提供;端口管理负责分配这些端口以避免冲突。

## 冲突策略

当本地站点需要的端口被占用时,应用的配置策略:

- `AUTO_KILL` —— 停止冲突的服务。
- `ALERT` —— 通知并由你决定。

(`REASSIGN` —— 另选端口 —— 是引擎对未配置端口的内部回退,不是可选策略。)

## 说明

本地站点通过端口管理分配端口,并在停止时释放,因此端口不会在应用之间 —— 或并排安装的多个 WebToApp 生成应用之间 —— 泄漏。
